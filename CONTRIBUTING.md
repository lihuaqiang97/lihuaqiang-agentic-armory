# Contributing to lihuaqiang-agentic-armory

首先，感谢你花时间为本项目做贡献！🎉

## 如何参与贡献？

### 报告 Bug 或提出改进建议

如果你发现某个提示词效果不佳，或有新的 Skill 想法：
1. 检查是否已有相关 [Issue](https://github.com/lihuaqiang/lihuaqiang-agentic-armory/issues)
2. 如果没有，新建一个 Issue，请描述：
   - 期望的行为
   - 实际的行为
   - 你使用的 Agent 产品及其版本（如 Claude Code vX.X）

### 提交 Pull Request

1. Fork 本仓库并从 `main` 创建分支
2. 如果添加了代码，请补充测试
3. 确保代码符合规范
4. 在 `CHANGELOG.md` 的 `[Unreleased]` 部分记录你的修改

## 风格指南

- **提示词（Prompts）**：保持模块化，避免硬编码个人信息
- **脚本（Scripts）**：使用 Python 3.10+ 或 Bash，包含必要的注释
- **提交信息（Commits）**：使用清晰的描述（如 `fix(blog-writer): reduce repetition`）

## How Can I Contribute?

### Reporting Bugs or Suggesting Enhancements

If you find a prompt that isn't working well or have an idea for a new skill:
1. Check if an Issue already exists.
2. If not, open a new Issue. Please describe:
   - The expected behavior
   - The actual behavior
   - The agent product and version you are using (e.g., Claude Code vX.X)

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure your code follows the style guide.
4. Update the `CHANGELOG.md` with your changes under `[Unreleased]`.

## Style Guide

- **Prompts**: Keep them modular. Avoid hardcoding personal data.
- **Scripts**: Use Python 3.10+ or Bash. Include necessary comments.
- **Commits**: Use clear, descriptive commit messages (e.g., `fix(blog-writer): reduce repetition`).
